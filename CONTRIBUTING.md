# Contributing

This repository is a pull-request practice lab.

1. Fork this repository to your other account.
2. Create a branch from the fork's `main`, e.g. `feature/delete-task`.
3. Implement one small feature and add corresponding tests.
4. Run `python -m unittest discover -s tests -v`.
5. Commit with a descriptive message, e.g. `feat: add task deletion`.
6. Push your branch to your fork and open a PR to the original repo's `main`.
7. Ask Account 1 to review. Respond to comments with new commits.
8. Account 1 approves and merges. Sync the fork before your next PR.

To see a **Verified** badge for local commits, configure SSH or GPG commit signing in Git and register the public signing key with the GitHub account making the commits.
